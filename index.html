Carga masiva de imágenes

Inicia sesión con la cuenta administradora para subir imágenes.

Selecciona imágenes JPG, PNG o WEBP. El nombre del archivo, sin extensión, debe coincidir exactamente con el código del producto (por ejemplo, ABC-123.jpg). Las imágenes mayores de 3 MB se optimizan automáticamente antes de subirlas.

Las imágenes se cargan una por una. Si un producto ya tiene imagen, se conserva y el archivo se reporta como omitido.
